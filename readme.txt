== Description ==
Este plugin permite gestionar la venta de tickets para eventos directamente desde WooCommerce. Cada entrada es nominativa, con código único y validable mediante un sistema propio de lectura de QR.

== Installation ==
1. Sube el plugin al directorio `/wp-content/plugins/`.
2. Activa el plugin a través del menú 'Plugins' en WordPress.
3. Configura tu producto de WooCommerce como tipo "Ticket".
4. Ajusta los datos del evento para su uso.
5. Crea una página para la comprobación de los tickets añadiendo el shortcode [ticket_validator]
